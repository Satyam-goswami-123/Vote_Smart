# 🗳️ VoteSmart India

VoteSmart India is a modern, interactive web application designed to simplify and educate users about the election process in India. It acts as a smart assistant that guides users through voter registration, eligibility, important timelines, and polling information in an engaging and user-friendly way.

---

## 🚀 Features

- 🧠 AI-powered Election Assistant (Gemini API)
- 📍 Polling Booth Locator (Google Maps API)
- ✅ Eligibility Checker for voters
- 📊 Personalized Dashboard with readiness score
- 🌐 Multi-language Support (Google Translate API)
- 🔐 Secure Authentication (Firebase Auth)
- ☁️ Real-time Database (Firebase Firestore)
- 🌙 Light/Dark Mode UI
- 📱 Fully Responsive Design

---

## 🛠️ Tech Stack

- **Frontend:** React + Vite + Tailwind CSS  
- **Backend:** Firebase (Authentication & Firestore)  
- **APIs Used:**
  - Google Maps API
  - Gemini API
  - Google Translate API
